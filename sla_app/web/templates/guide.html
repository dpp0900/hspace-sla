Basic Structure

현재 MVP는 Android Appium 실행만 지원합니다. YAML은 suite metadata, app target, SLA thresholds, scenarios로 구성됩니다.

name: Android Smoke
app:
  platform: android
  apk: test-apk/build/hspace-test-app-debug.apk
thresholds:
  max_duration_ms: 30000
  max_assertion_failures: 0
  max_metric_violations: 0
scenarios:
  - name: launch and capture
    steps:
      - action: launch_app
      - action: wait
        timeout_ms: 1000
      - action: screenshot
        name: launch
Field Required What it does
nameYesSuite 이름입니다. 웹 UI와 결과에 표시됩니다.
appYesAndroid 실행 대상입니다.
thresholdsNoSuite 전체 SLA 기준입니다.
scenariosYes실행할 scenario 목록입니다. 최소 1개가 필요합니다.

App Target

APK install

app:
  platform: android
  apk: test-apk/build/hspace-test-app-debug.apk

Installed app

app:
  platform: android
  app_package: com.example.myapp
  app_activity: .MainActivity
  app_wait_activity: com.example.myapp.*
  no_reset: true
Field Required Description
platformNo기본값은 android입니다. 현재 다른 platform은 거부됩니다.
apkConditional설치 후 실행할 APK 경로입니다.
app_packageConditional이미 설치된 앱의 package 이름입니다.
app_activityConditional이미 설치된 앱의 launch activity입니다.
app_wait_activityNoSplash activity가 있을 때 Appium에 전달됩니다.
no_resetNotrue면 앱 데이터를 유지합니다.

Thresholds

thresholds는 suite 루트와 scenario 안에 둘 수 있습니다.

thresholds:
  max_duration_ms: 30000
  max_assertion_failures: 0
  max_metric_violations: 0
  required_assertions: 1
  metrics:
    memory_mb:
      max: 256
Field Default Description
max_duration_msnoneScenario 최대 실행 시간입니다.
max_assertion_failures0허용할 assertion 실패 수입니다.
max_metric_violations0허용할 metric 위반 수입니다.
required_assertions0성공해야 하는 assertion step 최소 개수입니다.
metrics{}수집 metric에 적용할 min/max 기준입니다.

Selectors

tap, input, assert_exists에서 사용할 수 있습니다. text와 selector를 같이 넣으면 현재 Android 어댑터는 text를 우선합니다.

Actions

launch_app

앱 실행 세션을 시작합니다. 에뮬레이터 부팅, Appium 연결, driver 생성이 여기서 일어납니다.

- action: launch_app

tap

selector 또는 text로 요소를 찾아 탭합니다.

- action: tap
  selector: id=com.example:id/login
  timeout_ms: 5000

input

selector로 요소를 찾아 value를 입력합니다.

- action: input
  selector: id=com.example:id/email
  value: user@example.com

wait

timeout_ms만큼 대기합니다. 기본값은 1000ms입니다.

- action: wait
  timeout_ms: 1000

assert_text

현재 page source에 text가 포함되어 있는지 확인합니다.

- action: assert_text
  text: Welcome

assert_exists

selector 또는 text로 요소 존재 여부를 확인합니다.

- action: assert_exists
  selector: id=com.example:id/home

screenshot

현재 화면을 artifacts/<run_id>/ 아래 PNG로 저장합니다.

- action: screenshot
  name: after-login

collect_metrics

현재 앱의 기술 지표를 수집합니다. 현재 기본 metric은 memory_mb입니다.

- action: collect_metrics

metric_check

이미 수집된 metric이 min/max 범위 안에 있는지 확인합니다.

- action: metric_check
  metric: memory_mb
  max: 256

Complete Examples

Installed app with assertions

name: Login Smoke
app:
  platform: android
  app_package: com.example.myapp
  app_activity: .MainActivity
  app_wait_activity: com.example.myapp.*
  no_reset: false
thresholds:
  max_duration_ms: 20000
  required_assertions: 2
scenarios:
  - name: login screen
    steps:
      - action: launch_app
      - action: assert_exists
        selector: id=com.example.myapp:id/email
      - action: assert_text
        text: Login
      - action: screenshot
        name: login-screen

Metric check

name: Memory SLA
app:
  platform: android
  apk: test-apk/build/hspace-test-app-debug.apk
thresholds:
  max_duration_ms: 30000
  max_metric_violations: 0
  metrics:
    memory_mb:
      max: 256
scenarios:
  - name: launch memory
    steps:
      - action: launch_app
      - action: wait
        timeout_ms: 1000
      - action: collect_metrics
      - action: metric_check
        metric: memory_mb
        max: 256

Validation Rules

  • name, app, scenarios가 필요합니다.
  • app.platform은 현재 android여야 합니다.
  • app.apk 또는 app_package + app_activity가 필요합니다.
  • 각 scenario는 name과 1개 이상의 steps가 필요합니다.
  • tap은 selector 또는 text가 필요합니다.
  • input은 selector와 value가 필요합니다.
  • assert_text는 text가 필요합니다.
  • assert_exists는 selector 또는 text가 필요합니다.
  • metric_check는 metric과 min/max 중 하나 이상이 필요합니다.
현재 제한: Android만 지원하며, browser/iOS/device farm, 자유 Python 코드, swipe/scroll/orientation 액션은 아직 제공하지 않습니다.
